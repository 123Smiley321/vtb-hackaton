# Хакатон ВТБ «Деньги под защитой» — CL Cup Moscow 2026

Решение кейса ВТБ по антифроду: снижение хищений и ошибочных ограничений при переводах в ДБО.

## Структура

| Папка | Что | Кто |
|---|---|---|
| [ml-models](ml-models) | Модели PaySim и Sparkov, пороги по цене ошибки, симуляция многоуровневой реакции, сравнение вариантов | Р1, Михайлова Ангелина |

## Главные результаты ML-части

- Порог по цене ошибки: в 8 раз меньше ложных блокировок (578 против 4 821) при полноте 96,5%.
- Многоуровневая реакция против бинарной приостановки: похищено −8,4%, ошибочных ограничений −30,2%, потеря NPS от ошибочных ограничений −21,7%.
